# THIÊT KẾ MẠCH PCB DẠNG XẾP CHỒNG ỨNG DỤNG CHO NGÀNH UAV
## Mục đích
- Vẽ lại sơ đồ nguyên lí sử dụng module WiFi (đã tích hợp sẵn anten) lên 1 board điều khối nguồn PMS
- Module tích hợp dạng stack HAT giống nguyên lí của Raspberry Pi
- Kết nối và truyền thông giữa MCU và module WiFi dùng chuẩn USB2.0
- Có module hạ áp và quản lí nguồn ổn áp cho module WiFi và dự phòng MCU

## Phạm vi
- Tích hợp lên thiết bị bay không người lái, thiết kế dạng stack để cho nhiều thiết bị khác có thể hoạt động cùng sau này
- Hoạt động đọc lập chỉ giao tiếp với MCU Radxa Zero 3W (Chưa có kế hoạch triển khai trên nhiều SBC hay MCU)
- Chỉ có chức năng truyền thông hình ảnh, video, dữ liệu từ FC và cảm biến tới Ground Control System (GCS)
